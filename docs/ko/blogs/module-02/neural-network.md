## 1. 인공신경망의 역할

인공신경망(Artificial Neural Network, ANN)은 입력값을 여러 층의 **가중합, 편향, 비선형 활성화 함수**로 변환하여 출력값을 예측하는 학습 가능한 함수입니다. 회귀 문제에서는 실숫값을, 분류 문제에서는 클래스에 대응하는 점수(또는 확률)를 출력하도록 모델을 설계합니다. 사람이 모든 규칙을 `if`문으로 작성하는 대신, 데이터와 손실 함수로부터 가중치 및 편향을 조정합니다.

다만 신경망은 데이터가 가진 편향이나 오류까지 학습할 수 있습니다. 깊은 모델이 언제나 얕은 모델보다 정확하다는 의미는 아닙니다.

## 2. 뉴런: 가중치, 편향, 활성화

```text
입력: x1, x2, ..., xn
가중합: z = w1*x1 + w2*x2 + ... + wn*xn + b
출력:   a = activation(z)
```

- **입력 x:** 원본 데이터의 수치 특징 또는 이전 층의 출력입니다.
- **가중치 w:** 각 입력의 영향력과 방향을 나타내는 학습 파라미터입니다.
- **편향 b:** 뉴런의 기준점을 이동시키는 학습 파라미터입니다. 입력이 0이어도 `z=b`가 가능합니다.
- **활성화 함수:** 합산된 값을 변환합니다. ReLU는 `max(0,z)`, sigmoid는 `1/(1+exp(-z))`입니다.

예를 들어 `x1=2, x2=1, w1=0.5, w2=-1, b=0.2`이면 `z=2×0.5+1×(-1)+0.2=0.2`, `ReLU(z)=0.2`입니다. 같은 입력이라도 파라미터가 달라지면 출력이 바뀝니다.

## 3. 입력층, 은닉층, 출력층

```text
입력층       은닉층 1       은닉층 2       출력층
 x ------> [뉴런들] -----> [뉴런들] -----> 예측
```

입력층은 데이터의 특징(feature)을 전달하고, 은닉층은 이전 특징들을 결합하여 새 표현을 만듭니다. 완전연결층의 여러 뉴런을 한꺼번에 계산하면 `z = W*x + b`라는 행렬식으로 표현할 수 있습니다. 출력층은 문제 정의에 맞춘 값이나 로짓(logit)을 반환합니다.

**왜 활성화 함수가 중요한가?** 층을 여러 개 쌓아도 전부 단순 선형/아핀 변환이면, 전체가 하나의 아핀 변환으로 합쳐집니다. ReLU 등 비선형 함수를 사용해야 신경망이 입력 사이의 비선형 관계를 학습할 수 있습니다. 단, 활성화 하나가 복잡한 관계를 반드시 학습하도록 보장하지는 않습니다.

## 4. 두 층짜리 신경망: 순전파 수치 실습

입력 뉴런 2개, 은닉 뉴런 2개, 이진 분류 출력 1개인 **2→2→1** 구조를 예로 들어 보겠습니다. 수치는 교육용으로 새로 구성했습니다.

```text
입력 x = [2, 1]

은닉 A: hA = ReLU( 0.5*2 - 1.0*1 + 0.2 ) = 0.2
은닉 B: hB = ReLU(-0.3*2 + 0.8*1 + 0.1 ) = 0.3

출력 로짓: z = 1.2*hA - 0.4*hB + 0.1
             = 1.2*0.2 - 0.4*0.3 + 0.1 = 0.22

sigmoid(z): p = 1 / (1 + exp(-0.22)) ≈ 0.5548
```

현재 설정된 파라미터로 출력값을 계산하는 과정이 **순전파(forward pass)** 입니다. 아직 학습하거나 가중치를 바꾸지 않았습니다. `p`는 확률처럼 사용할 수 있는 출력이지만, 별도 보정 및 평가 없이는 실제 발생 빈도를 정확히 의미한다고 보장할 수 없습니다.

## 5. 손실 계산: 얼마나 틀렸는가?

정답 `y=1`인 샘플에 대해 이진 교차 엔트로피(binary cross-entropy)를 적용하겠습니다.

```text
L = -[y*ln(p) + (1-y)*ln(1-p)]
  = -ln(0.5548)
  ≈ 0.5892
```

손실 함수는 모델의 현재 예측과 정답 사이의 차이를 최적화 가능한 하나의 수로 표현합니다. 회귀는 평균제곱오차(MSE), 다중 클래스 분류는 다중 클래스 교차 엔트로피 등을 선택할 수 있습니다. **학습 손실이 줄었다는 사실만으로 미지의 데이터에 대한 성능은 입증되지 않습니다.**

## 6. 신경망 학습: 역전파와 경사하강법

표준적인 학습 루프는 **미니배치 선택 → 순전파 → 손실 계산 → 역전파로 기울기 계산 → 옵티마이저로 파라미터 업데이트** 순서입니다.

역전파(backpropagation)는 미분의 연쇄법칙을 이용해 각 가중치·편향에 대한 `dL/d(parameter)`를 구하는 계산입니다. 경사하강법(gradient descent)은 계산된 기울기를 사용해 파라미터를 바꾸는 최적화 방법입니다. 두 개는 같은 알고리즘이 아닙니다.

```text
gradient = dL/dw
w_new = w_old - learning_rate * gradient
```

예제에서 sigmoid와 이진 교차 엔트로피를 결합하면 출력 로짓의 기울기는 `dL/dz = p-y ≈ -0.4452`입니다. 출력층 첫 가중치의 기울기는 `-0.4452 * hA ≈ -0.0890`이므로 학습률 0.1의 SGD 한 단계 후 `w=1.2-0.1*(-0.0890)=1.2089`가 됩니다. 여기서는 한 가중치의 계산만 보여 주었습니다. **실제 전체 신경망을 학습하려면 은닉층의 모든 가중치와 편향에 대한 기울기도 계산하여 갱신해야 합니다.**

학습률이 과도하면 손실이 발산하거나 진동할 수 있고, 너무 낮으면 학습이 느려집니다. 깊은 신경망에서는 기울기 소실·폭발, 과적합 등도 살펴봐야 합니다.

## 7. Python으로 직접 확인

아래 코드는 외부 패키지 없이 예제의 **순전파와 출력층에 대한 한 번의 갱신만** 수행합니다. 은닉층은 고정되어 있으므로 완전한 신경망 학습 코드와는 구분해야 합니다.

```python
from math import exp, log

def relu(v):
    return max(0.0, v)

x1, x2 = 2.0, 1.0
h1 = relu(0.5*x1 - x2 + 0.2)
h2 = relu(-0.3*x1 + 0.8*x2 + 0.1)
w1, w2, b = 1.2, -0.4, 0.1
p = 1 / (1 + exp(-(w1*h1 + w2*h2 + b)))
print("before:", round(p, 4), round(-log(p), 4))

y, lr = 1.0, 0.1
dz = p - y
w1 -= lr * dz * h1
w2 -= lr * dz * h2
b -= lr * dz
p2 = 1 / (1 + exp(-(w1*h1 + w2*h2 + b)))
print("after: ", round(p2, 4), round(-log(p2), 4))
```

기대값: 수정 전 `p≈0.5548, loss≈0.5892`, 출력층을 갱신한 후 `p≈0.5672, loss≈0.5671`입니다. 한 샘플의 손실 감소는 일반화 성능 향상과 다릅니다.

## 8. 설계 및 실무 검증

| 관찰 | 주요 확인 사항 | 조치 예시 |
| --- | --- | --- |
| 학습 손실이 거의 줄지 않음 | 학습률, 데이터 오류, 활성화 포화 | 작은 배치 하나에 과적합되는지 시험 |
| 학습 손실 감소·검증 손실 증가 | 과적합, 데이터 분리 오류 | 검증셋 재점검, 정규화·조기 종료 |
| 출력이 한쪽 클래스에 치우침 | 레이블 불균형, 출력층·손실 불일치 | 혼동행렬, 정밀도·재현율 검증 |
| 일부 ReLU 뉴런이 계속 0 | dead ReLU 가능성 | 학습률·초기화 및 활성화 분포 확인 |
| 손실이 NaN으로 변경 | 수치 불안정, 과도한 학습률 | 안정적인 로짓 기반 손실 확인 |

테스트 데이터는 학습과 모델 선정에서 분리하여 최종 평가에 사용합니다. 이미지 분류·음성 인식·자연어 처리·이상 탐지 등에서 신경망을 활용하지만 모델의 구조와 장단점은 작업에 따라 달라집니다. 작은 구조화 데이터에서는 선형 모델이나 트리 모델이 더 효율적일 수도 있습니다.
