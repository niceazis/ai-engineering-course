# 지도학습 vs 비지도학습 — 원문 흐름을 따라가는 한국어 상세 학습 노트

> 원문: https://outcomeschool.com/blog/supervised-vs-unsupervised-learning  
> 원저자: Amit Shekhar / Outcome School  
> 문서 성격: **원문 전체 직역본이 아니라, 원문의 핵심 설명 순서와 비교 포인트를 충실히 따라가면서 한국어로 다시 풀어쓴 상세 학습 노트**

---

## 이 글에서 반드시 이해해야 할 것

이 글의 핵심은 “지도학습과 비지도학습의 정의”를 외우는 것이 아니라, **정답(label)이 있느냐 없느냐에 따라 학습 문제 자체가 어떻게 달라지는지**를 이해하는 것입니다.

끝까지 읽으면 다음을 설명할 수 있어야 합니다.

1. 지도학습과 비지도학습의 가장 중요한 차이
2. Classification과 Regression이 왜 지도학습에 속하는지
3. Clustering이 왜 비지도학습에 속하는지
4. 정답이 없는 상태에서도 모델이 무엇을 학습할 수 있는지
5. Self-Supervised Learning이 두 범주와 어떻게 연결되는지
6. 어떤 실무 문제에서 어느 접근을 선택해야 하는지

## 1. 가장 짧은 구분: 정답이 있는가?

지도학습과 비지도학습을 나누는 가장 간단한 기준은 **학습 데이터에 정답이 포함되어 있는가**입니다.

### 지도학습

데이터가 다음 형태입니다.

```text
입력 X + 정답 y
```

예:

| 이메일 내용 | 정답 |
|---|---|
| "무료 당첨..." | 스팸 |
| "회의 일정..." | 정상 |

모델은 입력을 보고 예측한 뒤, 실제 정답과 비교하면서 학습합니다.

```text
입력 -> 예측 -> 정답과 비교 -> 오차 계산 -> 파라미터 수정
```

### 비지도학습

데이터에 정답이 없습니다.

```text
입력 X만 존재
```

예:

| 고객 |
|---|
| 고객 A의 구매 패턴 |
| 고객 B의 구매 패턴 |
| 고객 C의 구매 패턴 |

“VIP / 일반 / 이탈위험” 같은 정답 라벨이 주어지지 않은 상태에서 데이터 안의 구조를 찾습니다.

---

## 2. 지도학습은 무엇을 학습하는가

지도학습에서는 모델이 입력과 정답 사이의 관계를 학습합니다.

수학적으로는 다음 함수를 근사한다고 생각할 수 있습니다.

```text
y ≈ f(X)
```

예를 들어 집값 예측에서는:

```text
면적, 위치, 층수, 연식 -> 집값
```

이라는 관계를 학습합니다.

분류에서는:

```text
이메일 내용 -> spam / not spam
```

처럼 범주를 예측합니다.

즉 지도학습은 **“정답이 무엇인지 알고 있는 문제”**에서 강합니다.

---

## 3. 지도학습의 두 대표 문제

### 3.1 Classification

출력이 범주입니다.

예:

- 스팸 / 정상
- 불량 / 정상
- 고양이 / 개
- 이탈 / 유지

모델은 보통 각 클래스에 대한 점수나 확률을 출력합니다.

### 3.2 Regression

출력이 연속적인 숫자입니다.

예:

- 집값
- 매출
- 온도
- 배송 시간

핵심 차이는 출력의 형태입니다.

```text
Classification -> 범주
Regression -> 연속값
```

---

## 4. 지도학습의 학습 루프

지도학습은 이전 레슨의 머신러닝 기본 구조와 직접 연결됩니다.

```text
Training Data
   ↓
Model Prediction
   ↓
Compare with Label
   ↓
Loss
   ↓
Gradient / Optimization
   ↓
Parameter Update
```

정답이 있기 때문에 “얼마나 틀렸는지”를 직접 계산할 수 있습니다.

예를 들어 실제값이 100이고 예측값이 80이라면 오차를 계산할 수 있습니다.

분류에서는 실제 클래스와 예측 확률을 비교해 Cross-Entropy 같은 loss를 사용할 수 있습니다.

---

## 5. 비지도학습은 무엇을 학습하는가

비지도학습에서는 정답이 없기 때문에 “맞았다/틀렸다”를 직접 비교하기 어렵습니다.

대신 다음과 같은 구조를 찾습니다.

- 서로 비슷한 데이터끼리 묶기
- 고차원 데이터를 더 낮은 차원으로 표현하기
- 데이터의 숨은 분포나 패턴 찾기
- 정상 패턴에서 크게 벗어난 샘플 찾기

대표적으로 다음이 있습니다.

### Clustering

비슷한 샘플을 그룹으로 나눕니다.

### Dimensionality Reduction

많은 feature를 더 적은 차원으로 줄이면서 중요한 구조를 보존합니다.

### Anomaly Detection

일반적인 패턴과 매우 다른 데이터를 찾습니다.

---

## 6. Clustering 예제

온라인 쇼핑몰 고객 데이터가 있다고 하겠습니다.

각 고객에 대해:

- 월 구매 횟수
- 평균 주문 금액
- 최근 방문일
- 할인 쿠폰 사용률

같은 정보는 있지만 “고객 유형”이라는 정답은 없다고 가정합니다.

Clustering 알고리즘은 비슷한 행동을 보이는 고객을 묶을 수 있습니다.

예:

```text
Cluster 1: 자주 구매 + 고액
Cluster 2: 할인 때만 구매
Cluster 3: 최근 활동 감소
```

중요한 점은 모델이 처음부터 이런 이름을 알고 있는 것이 아니라는 것입니다.

모델은 단지 수학적으로 비슷한 그룹을 만든 뒤, 사람이 각 그룹의 의미를 해석합니다.

---

## 7. 비지도학습 결과는 “정답”이 아니다

Clustering에서 자주 생기는 오해입니다.

클러스터가 3개 나왔다고 해서 현실에 정확히 3종류의 고객이 존재한다는 뜻은 아닙니다.

결과는 다음에 따라 달라질 수 있습니다.

- 사용한 feature
- scaling 방법
- distance metric
- cluster 개수
- 알고리즘
- noise

따라서 비지도학습은 **발견(discovery)**에는 강하지만, 결과 해석에는 사람의 검증이 필요합니다.

---

## 8. 지도학습과 비지도학습을 나란히 비교하면

| 항목 | 지도학습 | 비지도학습 |
|---|---|---|
| 정답 Label | 있음 | 없음 |
| 목표 | 예측 | 구조 발견 |
| 대표 문제 | Classification, Regression | Clustering, Dimensionality Reduction |
| 성능 평가 | 비교적 명확 | 상대적으로 어려움 |
| 예 | 스팸 분류 | 고객 군집 |
| 핵심 질문 | “무엇을 예측할까?” | “어떤 구조가 숨어 있을까?” |

---

## 9. 평가 방법의 차이

지도학습은 정답이 있으므로 평가가 상대적으로 명확합니다.

분류:

- Accuracy
- Precision
- Recall
- F1
- ROC-AUC

회귀:

- MAE
- MSE
- RMSE

비지도학습은 정답이 없으므로 더 어렵습니다.

Clustering에서는:

- Silhouette Score
- Intra-cluster distance
- Inter-cluster distance

같은 내부 지표를 사용할 수 있지만, 실제 비즈니스적으로 의미 있는 그룹인지까지 보장하지는 않습니다.

---

## 10. Self-Supervised Learning은 어디에 속하는가

현대 AI를 이해하려면 이 개념이 중요합니다.

Self-Supervised Learning은 사람이 정답을 직접 붙이지 않지만 **데이터 자체에서 학습 목표를 만들어냅니다.**

예를 들어 LLM은:

```text
"오늘 날씨가 매우"
```

다음에 올 token을 맞히는 식으로 학습할 수 있습니다.

원래 문장 자체가 정답을 제공합니다.

그래서:

- 사람이 label을 수작업으로 만들 필요는 없지만
- 실제 학습 과정에서는 명확한 prediction target이 존재합니다.

현대 LLM pretraining은 보통 Self-Supervised Learning으로 분류합니다.

---

## 11. Semi-Supervised Learning

현실에서는 label이 매우 비쌀 수 있습니다.

예를 들어 의료 영상 100만 장은 있지만 전문의가 라벨링한 이미지는 1만 장뿐일 수 있습니다.

이때:

- 소량의 labeled data
- 대량의 unlabeled data

를 함께 활용하는 접근이 Semi-Supervised Learning입니다.

---

## 12. 어떤 방식을 선택해야 하는가

가장 먼저 물어볼 질문은 이것입니다.

### 예측해야 할 명확한 정답이 있는가?

있다면 지도학습이 자연스러운 출발점입니다.

예:

```text
고객이 이탈할까?
이 이메일은 스팸인가?
내일 수요는 얼마인가?
```

### 정답은 없지만 데이터 구조를 이해하고 싶은가?

비지도학습이 적합할 수 있습니다.

예:

```text
고객을 행동 패턴으로 묶고 싶다.
문서들을 주제별로 나누고 싶다.
이상 거래를 탐색하고 싶다.
```

---

## 13. 실무에서 가장 중요한 함정

### Label 품질

지도학습에서는 잘못된 label이 모델의 목표 자체를 망칩니다.

### Data Leakage

예측 시점에는 알 수 없는 정보가 feature에 들어가면 offline 성능만 좋아집니다.

### 의미 없는 Cluster

비지도학습에서 수학적으로 잘 나뉜 그룹이 업무적으로 가치 있다는 보장은 없습니다.

### Scaling

거리 기반 Clustering은 feature scale에 매우 민감합니다.

---

## 14. 한 장 요약

```text
[정답 y 있음]
      ↓
Supervised Learning
      ↓
Classification / Regression
      ↓
예측 성능 최적화

[정답 y 없음]
      ↓
Unsupervised Learning
      ↓
Clustering / Dimensionality Reduction
      ↓
데이터 구조 발견
```

가장 중요한 문장:

> **지도학습은 정답을 이용해 입력과 출력의 관계를 배우고, 비지도학습은 정답 없이 데이터 자체의 구조를 찾습니다.**
