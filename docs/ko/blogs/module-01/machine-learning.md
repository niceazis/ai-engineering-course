# 1. 머신러닝이란?

머신러닝을 가장 간단히 설명하면 다음과 같습니다.

> **사람이 문제별 규칙을 하나하나 코드로 작성하는 대신, 데이터에서 규칙을 찾도록 모델을 학습시키는 방법입니다.**

전통적인 프로그램에서는 사람이 규칙을 직접 정합니다.

예를 들어 스팸 메일을 판별한다고 해보겠습니다.

사람이 다음과 같은 규칙을 코드로 만들 수도 있습니다.

```text
제목에 "무료"가 들어가면 스팸 점수 +1
본문에 특정 링크가 많으면 스팸 점수 +1
발신자가 차단 목록에 있으면 스팸
...
```

이 방식에서는 **사람이 규칙을 알고 있어야 하고, 그 규칙을 명시적으로 작성해야 합니다.**

머신러닝은 접근 방식이 다릅니다.

```text
많은 이메일 데이터
+ 각 이메일이 스팸인지 아닌지에 대한 정답
↓
학습 알고리즘
↓
데이터에서 스팸과 정상 메일을 구분하는 패턴을 학습
```

즉, 문제마다 “이 조건이면 이것”이라는 코드를 사람이 전부 쓰는 대신, **일반적인 학습 알고리즘에 데이터를 주고 데이터 안에 숨어 있는 규칙을 찾아내게 합니다.**

---

## 1.1 같은 알고리즘도 데이터가 달라지면 다른 일을 배울 수 있다

원문에서 중요한 예가 하나 나옵니다.

분류(Classification) 알고리즘은 데이터를 여러 범주로 나누는 데 사용됩니다.

예를 들어 같은 종류의 분류 알고리즘이라도:

- 손글씨 숫자 이미지를 학습시키면 → 숫자 분류기
- 이메일을 학습시키면 → 스팸 분류기

가 될 수 있습니다.

핵심은 **알고리즘 자체보다 학습 데이터가 달라지면서 모델이 다른 패턴을 배우게 된다는 것**입니다.

이를 단순화하면 다음과 같습니다.

```text
같은 학습 방식
+ 다른 데이터
=
다른 패턴을 학습한 모델
```

따라서 머신러닝에서 매우 중요한 질문은 다음입니다.

> 기계는 사람이 규칙을 직접 입력하지 않았는데 어떻게 규칙을 찾는가?

원문은 이 질문을 아주 작은 숫자 데이터로 설명합니다.

---

# 2. 데이터 안에 숨어 있는 패턴 찾기

다음과 같은 데이터가 있다고 해보겠습니다.

| x1 | x2 | y |
|---:|---:|---:|
| 4 | 2 | 8 |
| 1 | 2 | 5 |
| 0 | 5 | 10 |
| 2 | 1 | 4 |

각 행에는 입력값 `x1`, `x2`와 결과값 `y`가 있습니다.

이 표를 잠깐 보고 규칙을 찾아보면 다음 관계를 발견할 수 있습니다.

```text
y = x1 + 2 × x2
```

확인해보겠습니다.

첫 번째 행:

```text
x1 = 4
x2 = 2

y = 4 + 2 × 2
  = 8
```

두 번째 행:

```text
x1 = 1
x2 = 2

y = 1 + 2 × 2
  = 5
```

세 번째 행:

```text
x1 = 0
x2 = 5

y = 0 + 2 × 5
  = 10
```

네 번째 행:

```text
x1 = 2
x2 = 1

y = 2 + 2 × 1
  = 4
```

모든 데이터가 같은 규칙을 따릅니다.

---

# 3. 이 규칙을 모델 형태로 표현하기

위 식을 조금 일반적으로 바꿔보겠습니다.

```text
y = w1 × x1 + w2 × x2
```

여기서:

- `x1`, `x2`: 입력
- `w1`, `w2`: 입력의 중요도를 나타내는 weight
- `y`: 결과

현재 데이터에서는 정답이 다음입니다.

```text
w1 = 1
w2 = 2
```

따라서:

```text
y = 1 × x1 + 2 × x2
```

가 됩니다.

이제 매우 중요한 개념이 나옵니다.

> **머신러닝에서 “패턴을 찾는다”는 것은 이런 weight 값을 데이터로부터 찾아낸다는 의미로 이해할 수 있습니다.**

이 예제에서 모델이 배워야 할 핵심은 `w1=1`, `w2=2`입니다.

---

# 4. 모델이란 무엇인가?

이 예제의 모델은 다음 식입니다.

```text
ŷ = w1 × x1 + w2 × x2
```

여기서 `ŷ`는 “y-hat”이라고 읽으며, **모델이 계산한 예측값**입니다.

실제 정답과 구분하기 위해 다음처럼 표기합니다.

- `y`: 실제 데이터에 있는 정답
- `ŷ`: 현재 모델이 계산한 예측값

아직 weight가 정확하지 않으면 `ŷ`는 `y`와 다를 수 있습니다.

학습의 목적은 이 차이를 줄이는 것입니다.

---

# 5. 학습한 weight로 처음 보는 입력을 예측하기

만약 모델이 다음 weight를 정확히 학습했다면:

```text
w1 = 1
w2 = 2
```

새로운 입력도 계산할 수 있습니다.

예를 들어 학습 데이터에는 없었던 입력:

```text
x1 = 3
x2 = 4
```

를 넣어보겠습니다.

```text
ŷ = 1 × 3 + 2 × 4
  = 3 + 8
  = 11
```

즉, 모델은 원래 표에 없던 입력에 대해서도 `11`이라는 결과를 예측합니다.

이것이 머신러닝 모델을 학습시키는 핵심 이유입니다.

> **과거 데이터에서 관계를 학습하고, 그 관계를 새로운 데이터에 적용합니다.**

---

# 6. 사람이 직접 규칙을 찾으면 되지 않을까?

위 데이터는 행이 4개뿐이고 입력도 `x1`, `x2` 두 개뿐입니다.

사람이 직접 계산해도 규칙을 찾을 수 있습니다.

하지만 실제 문제는 전혀 다릅니다.

예를 들어 다음과 같은 상황을 생각해볼 수 있습니다.

- 데이터 행이 100만 개
- 입력 변수가 500개
- 입력끼리 복잡하게 상호작용
- 완벽한 직선 관계가 아님
- 데이터에 노이즈가 있음
- 관계가 시간에 따라 변함

이 경우 사람이 표를 보고 직접 식을 찾는 것은 사실상 불가능합니다.

바로 이 지점에서 머신러닝이 유용합니다.

원문의 핵심 흐름을 압축하면 다음과 같습니다.

```text
데이터를 받는다
↓
데이터에 숨어 있는 패턴을 찾는다
↓
그 패턴을 표현하는 weight를 학습한다
↓
학습한 weight를 새로운 입력에 사용한다
```

---

# 7. “Weight가 모델의 지식이다”라는 말

이 간단한 모델에서는:

```text
w1 = 1
w2 = 2
```

라는 숫자가 바로 데이터 관계를 설명합니다.

따라서 이 예제에서는 weight가 모델이 배운 “지식”이라고 볼 수 있습니다.

물론 현대 신경망이나 LLM에서는 특정 weight 하나에 하나의 지식이 저장되는 식으로 단순하게 해석할 수는 없습니다.

하지만 큰 개념에서는 여전히 같습니다.

> 학습이 끝난 모델의 동작은 학습된 parameter 값들에 의해 결정됩니다.

따라서 아주 단순화하면:

```text
Training = 좋은 weight를 찾는 과정
```

이라고 이해할 수 있습니다.

---

# 8. 그런데 weight는 처음부터 어떻게 아는가?

모델은 처음부터 `w1=1`, `w2=2`라는 정답을 알지 못합니다.

학습을 시작할 때는 보통 적절한 초기값에서 출발합니다.

원문의 단순 예제에서는:

```text
w1 = 0
w2 = 0
```

부터 시작합니다.

현재 모델은:

```text
ŷ = 0 × x1 + 0 × x2
```

이므로 어떤 입력을 넣어도 예측값이 0입니다.

첫 데이터:

```text
x1 = 4
x2 = 2
실제 y = 8
```

에 대해:

```text
예측 ŷ = 0
```

가 됩니다.

당연히 크게 틀렸습니다.

---

# 9. 실제값과 예측값의 차이

원문에서는 가장 단순한 형태로 오차를 다음처럼 설명합니다.

```text
Error = 실제값 - 예측값
      = y - ŷ
```

예를 들어:

```text
실제 y = 8
예측 ŷ = 0

Error = 8 - 0
      = 8
```

오차가 크다는 것은 현재 weight가 데이터를 잘 설명하지 못한다는 뜻입니다.

따라서 모델은 다음 질문에 답해야 합니다.

> weight를 어느 방향으로 얼마나 바꾸면 다음 예측이 더 좋아질까?

---

# 10. 머신러닝 학습의 반복 과정

학습 과정은 다음처럼 이해할 수 있습니다.

1. weight를 초기화한다.
2. 현재 weight로 예측한다.
3. 실제값과 비교한다.
4. 얼마나 틀렸는지 계산한다.
5. 오차가 줄어드는 방향으로 weight를 조금 수정한다.
6. 다시 예측한다.
7. 이 과정을 반복한다.

이를 그림으로 보면:

```text
현재 weight
   ↓
예측 ŷ 계산
   ↓
실제 y와 비교
   ↓
오차 계산
   ↓
weight 수정
   ↓
다시 예측
   ↓
반복
```

이 전체 반복 과정이 **Training(학습)**입니다.

---

# 11. Step 1 — 모든 weight가 0인 상태

초기 상태:

```text
w1 = 0
w2 = 0
```

모든 행의 예측값은 0이 됩니다.

| x1 | x2 | 실제 y | 예측 ŷ | 오차 y-ŷ |
|---:|---:|---:|---:|---:|
| 4 | 2 | 8 | 0 | 8 |
| 1 | 2 | 5 | 0 | 5 |
| 0 | 5 | 10 | 0 | 10 |
| 2 | 1 | 4 | 0 | 4 |

현재 모델은 사실상 아무것도 배우지 못한 상태입니다.

---

# 12. Step 2 — weight를 조금 수정

몇 번의 계산을 거쳐 weight를 다음처럼 움직였다고 해보겠습니다.

```text
w1 ≈ 0.225
w2 ≈ 0.400
```

첫 번째 데이터의 예측을 계산하면:

```text
ŷ = 0.225 × 4 + 0.400 × 2
  = 0.9 + 0.8
  = 1.7
```

실제값은 8이므로:

```text
Error = 8 - 1.7
      = 6.3
```

처음의 오차 8보다 줄었습니다.

전체 데이터에 대해서도 아직 많이 틀리지만, 모델은 조금씩 올바른 방향으로 이동하고 있습니다.

---

# 13. Step 3 — 다시 weight 수정

다음 단계에서는 weight가 다시 조정됩니다.

대략:

```text
w1 ≈ 0.402
w2 ≈ 0.719
```

첫 번째 데이터:

```text
x1 = 4
x2 = 2
```

의 예측은 대략:

```text
ŷ ≈ 0.402 × 4 + 0.719 × 2
  ≈ 3.05
```

정답은 8이므로 여전히 차이가 크지만, 이전 단계보다 좋아졌습니다.

중요한 것은 한 번에 정답 weight를 찾는 것이 아니라:

```text
조금 더 나은 weight
→ 조금 더 나은 weight
→ 조금 더 나은 weight
→ ...
```

처럼 반복해서 접근한다는 점입니다.

---

# 14. 충분히 반복하면 어떻게 되는가?

이 예제에서는 반복이 계속되면서 weight가 점차 다음 값에 가까워집니다.

```text
w1 → 1
w2 → 2
```

충분히 학습된 뒤에는:

| x1 | x2 | 실제 y | 예측 ŷ |
|---:|---:|---:|---:|
| 4 | 2 | 8 | 8 |
| 1 | 2 | 5 | 5 |
| 0 | 5 | 10 | 10 |
| 2 | 1 | 4 | 4 |

처럼 실제값과 예측값이 일치합니다.

즉:

```text
Error → 0
```

가 됩니다.

이 데이터가 정확한 선형 관계로 만들어졌기 때문에 가능한 결과입니다.

실제 데이터에서는 노이즈와 불확실성이 있으므로 항상 오차가 0이 되는 것은 아닙니다.

---

# 15. 여기서 Gradient Descent가 등장한다

그렇다면 weight를 도대체 어떤 규칙으로 바꾸는 것일까요?

무작정 아무 숫자나 넣어보는 것은 비효율적입니다.

머신러닝에서는 일반적으로 **현재 오차를 줄이는 방향**을 계산해서 weight를 수정합니다.

대표적인 방법이 **Gradient Descent(경사하강법)**입니다.

직관적으로는 다음과 같습니다.

```text
현재 위치 = 현재 weight
산의 높이 = loss
내리막 방향 = gradient가 알려주는 정보
목표 = 더 낮은 loss
```

즉, 경사하강법은:

> 현재 weight에서 어느 방향으로 움직이면 예측 오차가 줄어드는지를 계산해, 그 방향으로 조금씩 이동하는 방법

이라고 이해하면 됩니다.

이 글에서는 Gradient Descent의 수학 자체보다 **왜 필요한가**를 이해하는 것이 중요합니다.

---

# 16. Error와 Loss는 어떻게 다른가?

원문에서는 입문 설명을 위해:

```text
Error = y - ŷ
```

처럼 설명합니다.

실제 머신러닝 학습에서는 여러 데이터의 오차를 하나의 학습 목표로 합치기 위해 **Loss Function**을 사용합니다.

예를 들어 회귀에서는 평균제곱오차(MSE)를 많이 사용합니다.

```text
MSE = 평균((y - ŷ)²)
```

왜 제곱할까요?

- 양수/음수 오차가 서로 상쇄되는 것을 막고
- 큰 오차에 더 큰 패널티를 주고
- 미분 가능한 형태로 최적화하기 편하기 때문입니다.

따라서 실제 학습을 더 정확히 표현하면:

```text
예측
↓
Loss 계산
↓
Loss를 줄이는 방향 계산
↓
Weight 수정
```

입니다.

---

# 17. Learning Rate는 무엇인가?

Gradient Descent를 사용할 때 weight를 한 번에 얼마나 바꿀지 정하는 값이 필요합니다.

그 값이 **Learning Rate**입니다.

개념적으로:

```text
새로운 weight
=
현재 weight
-
learning_rate × gradient
```

입니다.

Learning Rate가 너무 크면:

- 정답 근처를 지나칠 수 있고
- loss가 불안정하게 움직일 수 있습니다.

너무 작으면:

- 학습은 안정적일 수 있지만
- 지나치게 오래 걸릴 수 있습니다.

즉, 학습은 **방향**뿐 아니라 **한 번에 이동하는 크기**도 중요합니다.

---

# 18. 원문의 Python 예제는 무엇을 보여주는가?

원문에는 NumPy를 이용해 이 과정을 직접 구현하는 간단한 코드가 나옵니다.

전체 코드의 핵심 논리는 다음과 같습니다.

```python
# 1. 데이터 준비
X = ...
y = ...

# 2. weight 초기화
w = [0, 0]

# 3. 여러 번 반복
for step in range(steps):

    # 현재 weight로 예측
    y_pred = X @ w

    # 실제값과 예측값 차이 계산
    error = y - y_pred

    # 오차가 줄어드는 방향 계산
    gradient = ...

    # weight 수정
    w = w - learning_rate * gradient
```

코드 문법보다 중요한 것은 구조입니다.

```text
Prediction
→ Error
→ Gradient
→ Weight Update
→ Repeat
```

이 구조가 이후 배우게 될 Neural Network 학습에서도 그대로 이어집니다.

# 19. 왜 1000번 같은 반복이 필요한가?

한 번의 weight 수정만으로 정답에 도달하지 않는 경우가 대부분입니다.

조금씩 수정하면서 점차 나아집니다.

예를 들어 이 글의 흐름에서는:

```text
초기:
w1 = 0
w2 = 0

↓

중간:
w1 ≈ 0.225
w2 ≈ 0.400

↓

다음:
w1 ≈ 0.402
w2 ≈ 0.719

↓

계속 반복

↓

최종적으로:
w1 ≈ 1
w2 ≈ 2
```

처럼 움직입니다.

즉, 학습은 “한 번 계산해서 정답 찾기”보다 **반복적인 최적화 과정**으로 이해하는 것이 정확합니다.

---

# 20. 학습이 끝난 후에는 무엇을 하는가?

weight를 충분히 잘 학습했다면 더 이상 매번 weight를 바꿀 필요가 없습니다.

새 입력이 들어오면 학습된 weight를 사용해서 결과만 계산하면 됩니다.

예를 들어:

```text
학습 완료:
w1 = 1
w2 = 2
```

새 입력:

```text
x1 = 3
x2 = 4
```

예측:

```text
ŷ = 1 × 3 + 2 × 4
  = 11
```

이렇게 **학습된 모델로 새 입력의 결과를 계산하는 과정**을 Inference(추론)라고 합니다.

---

# 21. Training과 Inference 구분하기

## Training

목표:

> 좋은 weight를 찾는다.

과정:

```text
데이터
→ 예측
→ loss
→ gradient
→ weight update
→ 반복
```

특징:

- 많은 계산 필요
- weight가 계속 바뀜
- 학습 데이터와 정답이 필요

## Inference

목표:

> 이미 학습된 모델로 새 입력을 처리한다.

과정:

```text
새 입력
→ 학습된 weight
→ 예측
```

특징:

- weight를 보통 수정하지 않음
- 학습보다 계산이 단순함
- 실제 제품 사용 단계에서 많이 수행됨

# 22. 머신러닝 엔지니어의 기본 Workflow

원문에서는 머신러닝 엔지니어의 작업을 크게 다음 흐름으로 정리합니다.

## 22.1 데이터를 이해한다

먼저 데이터가 무엇을 의미하는지 알아야 합니다.

예:

- 입력은 무엇인가?
- 정답은 무엇인가?
- 누락값은 있는가?
- 데이터는 어떤 범위인가?
- 예측 시점에 실제로 사용할 수 있는 정보인가?

## 22.2 적절한 모델을 선택한다

문제에 따라 모델이 달라질 수 있습니다.

예를 들어:

- 단순한 관계 → Linear Model
- 복잡한 경계를 가진 표 형태 데이터 → Tree 계열 모델
- 매우 복잡한 비선형 패턴 또는 이미지·음성·텍스트 → Deep Learning

## 22.3 모델을 학습한다

데이터를 이용해 weight 또는 parameter를 찾습니다.

## 22.4 평가한다

학습에 사용하지 않은 데이터에서도 잘 맞는지 확인합니다.

## 22.5 배포한다

새로운 실제 데이터에 대해 예측하도록 서비스에 연결합니다.

# 23. “Machine Learning = 데이터에서 좋은 weight를 학습하는 것”

이 문장은 매우 단순화된 표현이지만 이 글을 이해하는 데 핵심적입니다.

선형 모델에서는 정말로:

```text
어떤 weight가 데이터를 가장 잘 설명하는가?
```

가 학습의 중심입니다.

Neural Network에서는 weight 수가 수백만, 수십억, 수천억 개로 늘어나지만 큰 구조는 변하지 않습니다.

```text
데이터
→ 예측
→ 실제값과 비교
→ loss
→ gradient
→ parameter 수정
```

이라는 원리는 그대로입니다.

---

# 24. 머신러닝의 진짜 목표는 “암기”가 아니다

이 예제에서는 네 개 데이터를 모두 정확히 맞힐 수 있습니다.

하지만 현실에서는 단순히 학습 데이터를 외우는 것이 목표가 아닙니다.

더 중요한 것은:

> **학습할 때 보지 못한 새로운 데이터에도 잘 동작하는 것**

입니다.

이를 **Generalization(일반화)**이라고 합니다.

예를 들어 학습 과정에서 본 적 없는:

```text
x1 = 10
x2 = 3
```

을 넣었을 때, 올바른 패턴을 학습한 모델이라면:

```text
ŷ = 10 + 2 × 3
  = 16
```

을 계산할 수 있습니다.

이처럼 모델이 단순히 샘플을 외운 것이 아니라 **데이터 생성 규칙에 가까운 패턴을 학습했다면** 새로운 입력에도 대응할 수 있습니다.

# 25. 보충 설명 — 현실 데이터에서는 왜 더 어려운가?

원문의 예제는 학습 원리를 보여주기 위해 매우 깨끗한 데이터를 사용합니다.

현실에서는 다음 문제가 있습니다.

## 25.1 Noise

같은 입력이어도 측정 오차나 외부 요인 때문에 결과가 조금씩 달라질 수 있습니다.

## 25.2 입력 변수가 많음

`x1`, `x2` 두 개가 아니라 수백~수천 개일 수 있습니다.

## 25.3 관계가 선형이 아님

```text
y = w1*x1 + w2*x2
```

같은 직선 관계로 설명되지 않을 수 있습니다.

## 25.4 중요한 정보가 데이터에 없을 수 있음

모델은 주어진 입력만 사용할 수 있습니다.

## 25.5 데이터 분포가 변할 수 있음

과거 데이터에서 배운 패턴이 미래에도 그대로 유지된다는 보장은 없습니다.

따라서 실제 머신러닝은 단순히 “weight만 찾으면 끝”이 아니라 데이터 품질, 평가, 배포 후 모니터링까지 포함합니다.

# 26. AI 전체에서 Machine Learning은 어디에 위치하는가?

원문 후반에서는 AI 관련 용어의 포함 관계를 설명합니다.

```text
Artificial Intelligence

        └── Generative AI의 주요 현대 모델들
            └── Large Language Models
```

## 26.1 Artificial Intelligence — AI

가장 넓은 개념입니다.

사람이 수행하던 지능적인 작업을 컴퓨터가 수행하도록 만드는 다양한 방법을 포함합니다.

모든 AI가 반드시 머신러닝인 것은 아닙니다.

규칙 기반 AI도 AI에 포함될 수 있습니다.

---

## 26.2 Machine Learning — ML

AI의 한 분야입니다.

특징은:

> 데이터를 이용해 패턴을 학습한다.

는 것입니다.

이 글에서 본 `w1`, `w2` 학습이 가장 단순한 예입니다.

---

## 26.3 Deep Learning — DL

Machine Learning의 하위 분야입니다.

많은 layer로 구성된 Neural Network를 사용해 복잡한 패턴을 학습합니다.

이미지, 음성, 자연어처럼 입력 구조가 복잡한 문제에서 특히 중요합니다.

- 이미지
- 음성
- 음악
- 영상
- 코드

현대 Generative AI의 대부분은 Deep Learning을 기반으로 합니다.

## 26.5 Large Language Model — LLM

언어를 다루는 대규모 모델입니다.

대량의 텍스트로 학습해:

등을 수행합니다.

ChatGPT 같은 서비스의 핵심에도 LLM이 사용됩니다.

# 27. 이 글의 핵심을 한 단계씩 다시 연결하기

처음부터 끝까지 흐름을 하나로 연결하면 다음과 같습니다.

## 단계 1 — 데이터가 있다

```text
x1, x2 → y
```

## 단계 2 — 데이터에는 어떤 관계가 숨어 있다

이 예제에서는:

```text
y = x1 + 2*x2
```

## 단계 3 — 모델을 정의한다

```text
ŷ = w1*x1 + w2*x2
```

## 단계 4 — 처음에는 weight를 모른다

```text
w1 = 0
w2 = 0
```

## 단계 5 — 예측한다

```text
ŷ = 0
```

## 단계 6 — 실제값과 비교한다

```text
error = y - ŷ
```

## 단계 7 — weight를 수정한다

Gradient Descent 같은 최적화 방법을 사용합니다.

## 단계 8 — 계속 반복한다

```text
Predict
→ Compare
→ Update
→ Repeat
```

## 단계 9 — 좋은 weight를 찾는다

```text
w1 ≈ 1
w2 ≈ 2
```

## 단계 10 — 새로운 입력을 예측한다

```text
x1 = 3
x2 = 4

ŷ = 11
```

이 10단계가 이 글에서 설명하는 머신러닝 입문의 핵심입니다.

# 28. 처음 읽을 때 반드시 구분해야 할 용어

| 용어 | 의미 |
|---|---|
| `x` | 모델에 넣는 입력 |
| `y` | 실제 정답 |
| `ŷ` | 모델이 계산한 예측값 |
| Weight | 모델이 학습하는 숫자 |
| Model | 입력으로부터 출력을 계산하는 함수 |
| Error | 실제값과 예측값의 차이 |
| Loss | 학습을 위해 오차를 수치화한 목적 함수 |
| Gradient | loss가 어느 방향으로 얼마나 변하는지 알려주는 정보 |
| Gradient Descent | loss를 줄이는 방향으로 parameter를 수정하는 방법 |
| Learning Rate | parameter를 한 번에 얼마나 수정할지 정하는 값 |
| Training | parameter를 학습하는 과정 |
| Inference | 학습된 parameter로 새 입력을 처리하는 과정 |

아닙니다.

- Model: 예측하는 함수

입니다.
