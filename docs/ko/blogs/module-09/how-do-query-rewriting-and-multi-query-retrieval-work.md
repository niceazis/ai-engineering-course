# Query Rewriting과 Multi-Query Retrieval — 원문 대조 한국어 학습 노트

- 원문: https://outcomeschool.com/blog/how-do-query-rewriting-and-multi-query-retrieval-work
- 저자: Amit Shekhar (Outcome School)
- 원문 게시일: 2026-10-08
- 대조 범위: 검색 색인에 공개된 원문 본문·목차·예시를 확인해 핵심 주제와 사례를 대조함. 사이트 직접 페이지 열람은 실패했으므로 원문 전체 문장·그림·코드를 빠짐없이 대조한 완전 검증본은 아님.
- 작성 방식: 저작권을 존중하는 독립적인 한국어 상세 해설이며 원문 전체 번역이 아님.

## 1. 문제 정의

사용자의 원문 질문은 생략·지시대명사·잘못된 용어 때문에 검색에 부적합할 수 있습니다. 원문은 RAG의 검색 이전 단계에서 질문을 정리하는 두 접근을 비교합니다.

## 2. Query Rewriting

원 질문과 대화 맥락을 입력받아 **하나의 완결된 검색 질의**를 만듭니다. 원문의 고객지원 예시에서 'And what about the Basic one?'은 앞선 Pro 요금제 환불정책 대화를 참고해 'Basic 요금제 환불 정책은 무엇인가?'로 복원할 수 있습니다. 최종 답변은 원 질문의 의도에 맞춰 작성합니다.

## 3. 재작성 유형

대화 맥락을 반영한 독립형 질문 생성, 모호한 표현 명확화, 검색에 적합한 전문 용어 사용, 불필요한 표현 제거가 포함됩니다. 없는 제약을 임의로 추가하지 않아야 합니다.

## 4. Multi-Query Retrieval

질문을 여러 관점으로 재표현한 뒤 각각 검색하고 결과를 합칩니다. 하나의 재작성만으로 놓칠 수 있는 다른 용어·관점을 보완하지만 검색 횟수와 지연이 증가합니다.

## 5. Reciprocal Rank Fusion

원문은 여러 검색 결과를 합치는 방식으로 **RRF**를 다룹니다. 문서 d의 결합 점수는 일반적으로 `RRF(d) = Σ_i 1 / (k + rank_i(d))`로 표현합니다. 여기서 rank_i는 i번째 결과에서의 순위이며 k는 상위 순위의 과도한 영향력을 완화하는 상수입니다. 서로 다른 검색기의 원점수 스케일을 맞추지 않아도 됩니다.

## 6. 선택 기준

대화 맥락 복원과 모호성 해결이 주된 문제라면 Query Rewriting을 먼저 적용합니다. 검색 누락이 크고 다양한 관점이 필요하면 Multi-Query를 검토합니다. 원 질문과의 의미 보존, Recall@k, 지연·비용을 함께 평가합니다.

## 학습 점검

1. 이 기술의 입력, 처리 단계, 출력은 무엇인가?
2. 원문에서 제시한 예시가 왜 해당 기술의 장점과 한계를 드러내는가?
3. 실제 시스템에서 정확도·비용·안전성을 어떻게 검증할 것인가?

## 출처 검증 메모

원문의 공개 검색 색인에 나타난 핵심 개념·예제와 비교했습니다. 직접 페이지 전체를 안정적으로 열람할 수 없어 이미지·모든 코드 줄·모든 문단까지 1:1 확인했다고 주장하지 않습니다.
