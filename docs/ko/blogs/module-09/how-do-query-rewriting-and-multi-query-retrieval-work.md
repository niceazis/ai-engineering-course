## 1. 학습 목표

Query Rewriting은 모호하거나 짧은 사용자 질문을 검색 친화적으로 재작성합니다. Multi-Query는 동일한 정보 요구를 여러 관점의 검색 질의로 분해합니다.

## 2. 작동 원리

1. **원 질문 분석**
2. **의도·용어·제약 추출**
3. **재작성 또는 다중 질의 생성**
4. **각 질의 검색**
5. **결과 중복 제거·통합**
6. **재순위화**
7. **근거 기반 응답**

## 3. 실무 예시

'맥에서 로컬 모델 빠르게'를 'Apple Silicon 로컬 LLM 추론 최적화', 'Metal 가속', '양자화 선택' 등으로 확장할 수 있습니다.

## 4. 장점과 한계

원래 의도에서 벗어나는 질의 드리프트, 검색 호출 증가, 중복 결과 및 근거 혼합에 주의합니다.

## 5. 확인 질문

- 이 기법은 어떤 문제에서 단순한 접근보다 유리한가?
- 성능을 어떤 지표로 검증할 것인가?
- 비용·지연·정확도·보안 측면에서 어떤 실패가 가능한가?

## 6. 원문 대조 시 보완할 사항

원문 전체를 직접 확인한 후 정의, 설명 순서, 구체적 수치·수식, 원문의 사례 및 기술적 주장과의 차이를 검토해야 합니다. 검증 전에는 원문을 충실히 번역했다고 표시하지 않습니다.
