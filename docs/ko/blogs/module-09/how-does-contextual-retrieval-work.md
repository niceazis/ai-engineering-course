# Contextual Retrieval — 한국어 상세 학습 노트

> **원문 검증 한계:** Outcome School 원문 페이지 직접 열람에 실패했습니다. 따라서 이 문서는 원문의 상세 번역이나 목차 재현이 아니라, 공개된 레슨 제목과 일반적으로 확인 가능한 기술 개념을 바탕으로 작성한 독립적인 한국어 학습 해설입니다. 원문의 예시·수식·주장과 일치한다고 단정하지 않습니다.

- 원문: https://outcomeschool.com/blog/how-does-contextual-retrieval-work
- 출처: Outcome School, AI Engineering Course

## 1. 학습 목표

Contextual Retrieval은 청크를 독립적으로 임베딩하기 전에 문서 전체의 배경을 짧게 보강하여 검색 시 문맥 손실을 줄이는 접근입니다.

## 2. 작동 원리

1. **원문 수집**
2. **청크 분할**
3. **문서·청크를 함께 고려해 맥락 문장 생성**
4. **청크에 맥락 추가**
5. **임베딩 및 키워드 인덱싱**
6. **검색·재순위화**

## 3. 실무 예시

정책 문서의 '그는 30일 내 승인한다'라는 청크에 해당 조직·담당자·정책명을 덧붙이면 고립된 대명사로 인한 검색 오류를 줄일 수 있습니다.

## 4. 장점과 한계

맥락 생성 비용과 인덱스 크기가 증가하고, 생성된 배경이 사실과 다르면 검색 품질이 악화될 수 있습니다.

## 5. 확인 질문

- 이 기법은 어떤 문제에서 단순한 접근보다 유리한가?
- 성능을 어떤 지표로 검증할 것인가?
- 비용·지연·정확도·보안 측면에서 어떤 실패가 가능한가?

## 6. 원문 대조 시 보완할 사항

원문 전체를 직접 확인한 후 정의, 설명 순서, 구체적 수치·수식, 원문의 사례 및 기술적 주장과의 차이를 검토해야 합니다. 검증 전에는 원문을 충실히 번역했다고 표시하지 않습니다.
