# Tree of Thoughts — 원문 대조 한국어 학습 노트

- 원문: https://outcomeschool.com/blog/how-does-tree-of-thoughts-work
- 저자: Amit Shekhar (Outcome School)
- 원문 게시일: 2026-10-07
- 대조 범위: 검색 색인에 공개된 원문 본문·목차·예시를 확인해 핵심 주제와 사례를 대조함. 사이트 직접 페이지 열람은 실패했으므로 원문 전체 문장·그림·코드를 빠짐없이 대조한 완전 검증본은 아님.
- 작성 방식: 저작권을 존중하는 독립적인 한국어 상세 해설이며 원문 전체 번역이 아님.

## 1. 원문이 설명하는 문제

일반적인 단계별 추론(CoT)은 한 번 선택한 중간 추론을 따라 계속 진행하기 쉽습니다. 초기 선택이 틀리면 뒤에서 복구하기 어렵습니다. 원문은 이를 여러 후보 생각을 평가하고 탐색하는 구조로 확장합니다.

## 2. Thought와 상태

Thought는 전체 답이 아니라 다음 상태로 넘어가는 중간 추론 단위입니다. 트리의 노드는 현재까지의 부분 해법, 간선은 다음 생각을 나타냅니다. 문제마다 적절한 thought 단위와 종료 조건을 먼저 정해야 합니다.

## 3. 생성·평가·탐색

1. 현재 상태에서 서로 다른 후보 thought를 여러 개 생성합니다.
2. 각 후보가 제약을 만족하고 목표에 가까운지 평가합니다.
3. 좋은 후보를 우선 확장하고 실패한 분기는 폐기하거나 되돌립니다.
4. 정답을 찾거나 탐색 예산에 도달하면 종료합니다.

## 4. Game of 24 예제

원문은 **Game of 24**를 전체 예제로 다룹니다. 네 숫자에 산술 연산을 적용해 24를 만드는 문제에서는 중간 계산을 하나의 상태로 놓고, 가능한 연산을 여러 갈래로 확장합니다. 예를 들어 4, 7, 8, 8에서 `(7 - 4) × 8 = 24`를 만들면 남은 8을 함께 사용해야 한다는 제약을 놓치기 쉽습니다. 따라서 상태에는 사용한 숫자와 남은 숫자를 반드시 보존해야 합니다. 이 숫자 조합은 개념 설명용으로 작성한 예시이며 원문의 정확한 숫자라고 주장하지 않습니다.

## 5. 비용과 실패

후보 수를 b, 탐색 깊이를 d라고 하면 전수 탐색 노드 수는 최악의 경우 대략 O(b^d)까지 증가합니다. 평가기의 편향, 중복 분기, 토큰 비용, 응답 지연을 관리해야 합니다. 쉬운 질문에서는 단순 CoT가 더 경제적일 수 있습니다.

## 학습 점검

1. 이 기술의 입력, 처리 단계, 출력은 무엇인가?
2. 원문에서 제시한 예시가 왜 해당 기술의 장점과 한계를 드러내는가?
3. 실제 시스템에서 정확도·비용·안전성을 어떻게 검증할 것인가?

## 출처 검증 메모

원문의 공개 검색 색인에 나타난 핵심 개념·예제와 비교했습니다. 직접 페이지 전체를 안정적으로 열람할 수 없어 이미지·모든 코드 줄·모든 문단까지 1:1 확인했다고 주장하지 않습니다.
