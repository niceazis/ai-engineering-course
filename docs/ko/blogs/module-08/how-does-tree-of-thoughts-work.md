## 1. 학습 목표

Tree of Thoughts(ToT)는 하나의 추론 경로만 이어 가는 대신 여러 후보 생각을 생성·평가하고, 유망하지 않은 경로를 되돌리는 탐색형 추론 방식입니다.

## 2. 작동 원리

1. **문제 정의**
2. **여러 중간 생각 생성**
3. **후보 평가**
4. **선택·확장 또는 백트래킹**
5. **종료 조건 검사**

## 3. 실무 예시

단순 수학 문제는 Chain of Thought로 충분할 수 있지만, 제약이 많은 계획 문제에서는 후보 상태를 트리로 유지하는 편이 유리할 수 있습니다.

## 4. 장점과 한계

탐색 폭과 깊이가 증가하면 모델 호출 수·지연·비용이 증가합니다. 평가 함수가 부정확하면 잘못된 가지를 우선 탐색합니다.

## 5. 확인 질문

- 이 기법은 어떤 문제에서 단순한 접근보다 유리한가?
- 성능을 어떤 지표로 검증할 것인가?
- 비용·지연·정확도·보안 측면에서 어떤 실패가 가능한가?

## 6. 원문 대조 시 보완할 사항

원문 전체를 직접 확인한 후 정의, 설명 순서, 구체적 수치·수식, 원문의 사례 및 기술적 주장과의 차이를 검토해야 합니다. 검증 전에는 원문을 충실히 번역했다고 표시하지 않습니다.
