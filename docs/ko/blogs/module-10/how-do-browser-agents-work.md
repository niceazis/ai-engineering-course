## 1. 학습 목표

Browser Agent는 웹페이지를 관찰하고 탐색·클릭·입력 등의 행동을 계획하며 결과를 재확인하는 도구 사용형 에이전트입니다.

## 2. 작동 원리

1. **사용자 목표·권한 확인**
2. **DOM 또는 스크린샷 관찰**
3. **다음 행동 결정**
4. **브라우저 조작**
5. **화면 변화·오류 검증**
6. **반복 또는 승인 요청**

## 3. 실무 예시

상품 검색은 페이지 이동과 조건 필터링을 자동화할 수 있지만 결제·외부 전송 같은 영향 큰 동작은 별도 확인이 적절합니다.

## 4. 장점과 한계

동적 UI·로그인·CAPTCHA·페이지 변경으로 실패할 수 있습니다. 웹페이지의 지시를 신뢰된 사용자 명령과 구별하고 비밀정보 유출을 방지해야 합니다.
