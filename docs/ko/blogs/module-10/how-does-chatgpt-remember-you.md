# ChatGPT Memory — 한국어 상세 학습 노트

> **원문 검증 한계:** Outcome School 원문 페이지 직접 열람에 실패했습니다. 따라서 이 문서는 원문의 상세 번역이나 목차 재현이 아니라, 공개된 레슨 제목과 일반적으로 확인 가능한 기술 개념을 바탕으로 작성한 독립적인 한국어 학습 해설입니다. 원문의 예시·수식·주장과 일치한다고 단정하지 않습니다.

- 원문: https://outcomeschool.com/blog/how-does-chatgpt-remember-you
- 출처: Outcome School, AI Engineering Course

## 1. 학습 목표

대화형 AI의 기억은 현재 대화 문맥과 세션 간 유지되는 사용자 관련 정보로 구분해서 이해해야 합니다. 제품별 기억 기능·보관·삭제 정책은 변경될 수 있습니다.

## 2. 작동 원리

1. **사용자 입력**
2. **기억할 만한 사실 또는 선호 식별**
3. **제품 정책에 따른 저장·요약**
4. **이후 대화에서 관련성 판단**
5. **응답에 반영**
6. **사용자 정정·삭제 통제**

## 3. 실무 예시

사용자가 답변 언어를 한국어로 선호한다는 정보는 후속 대화에 도움이 될 수 있지만, 과거의 일시적 일정은 최신성을 확인해야 합니다.

## 4. 장점과 한계

기억은 완전한 대화 로그나 진실의 보증이 아닙니다. 민감 정보·오래된 선호·잘못된 추론을 구분하고 제품의 실제 설정과 정책을 확인해야 합니다.

## 5. 확인 질문

- 이 기법은 어떤 문제에서 단순한 접근보다 유리한가?
- 성능을 어떤 지표로 검증할 것인가?
- 비용·지연·정확도·보안 측면에서 어떤 실패가 가능한가?

## 6. 원문 대조 시 보완할 사항

원문 전체를 직접 확인한 후 정의, 설명 순서, 구체적 수치·수식, 원문의 사례 및 기술적 주장과의 차이를 검토해야 합니다. 검증 전에는 원문을 충실히 번역했다고 표시하지 않습니다.
