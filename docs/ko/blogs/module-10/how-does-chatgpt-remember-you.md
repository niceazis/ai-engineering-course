# ChatGPT Memory — 원문 대조 한국어 학습 노트

- 원문: https://outcomeschool.com/blog/how-does-chatgpt-remember-you
- 저자: Amit Shekhar (Outcome School)
- 원문 게시일: 2026-10-12
- 대조 범위: 검색 색인에 공개된 원문 본문·목차·예시를 확인해 핵심 주제와 사례를 대조함. 사이트 직접 페이지 열람은 실패했으므로 원문 전체 문장·그림·코드를 빠짐없이 대조한 완전 검증본은 아님.
- 작성 방식: 저작권을 존중하는 독립적인 한국어 상세 해설이며 원문 전체 번역이 아님.

## 1. 원문의 핵심 모델

원문은 LLM 가중치가 대화 때마다 수정되는 것이 아니라, 모델 바깥의 관련 메모를 후속 대화의 입력 문맥에 포함하는 방식으로 기억을 설명합니다. 이는 기억을 모델 학습과 구별하는 데 유용한 개념 모델입니다.

## 2. Context Window와 세션 내 기억

한 번의 대화에서는 앞선 메시지가 입력 컨텍스트에 들어와 문맥을 제공합니다. 컨텍스트 한도, 요약, 세션 경계로 모든 내용이 영구히 유지되는 것은 아닙니다.

## 3. 기억의 범주

원문은 **Saved memories**, **Reference chat history**, **Custom Instructions**를 구분합니다. 각각 명시적·요약된 사용자 정보, 과거 대화에서 유용한 맥락의 참조, 사용자가 지정한 응답 지침이라는 서로 다른 역할을 가집니다.

## 4. 조회·정정·삭제

사용자는 저장된 정보가 무엇인지 확인하고 부정확한 항목을 정정하며 개인화 설정을 조정할 필요가 있습니다. 구체적인 메뉴명과 삭제 방식은 제품 버전과 정책에 따라 바뀌므로 원문의 2026년 10월 설명을 현재 제품의 보장된 UI 절차로 단정하지 않습니다.

## 5. 효용과 실패

언어 선호·장기 프로젝트·반복 습관에는 도움이 될 수 있지만, 오래된 사실을 현재 사실로 오인하거나 관련 없는 과거 정보를 불러올 수 있습니다. 민감 정보, 출처, 시점, 사용자의 최신 지시를 우선 확인해야 합니다.

## 학습 점검

1. 이 기술의 입력, 처리 단계, 출력은 무엇인가?
2. 원문에서 제시한 예시가 왜 해당 기술의 장점과 한계를 드러내는가?
3. 실제 시스템에서 정확도·비용·안전성을 어떻게 검증할 것인가?

## 출처 검증 메모

원문의 공개 검색 색인에 나타난 핵심 개념·예제와 비교했습니다. 직접 페이지 전체를 안정적으로 열람할 수 없어 이미지·모든 코드 줄·모든 문단까지 1:1 확인했다고 주장하지 않습니다.
