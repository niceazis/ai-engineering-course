## 사용 방법

1. 먼저 [한국어 메인 README](../../README.ko.md)에서 전체 커리큘럼을 확인합니다.
2. 각 모듈 문서에서 레슨별 한국어 요약을 읽습니다.
3. 더 깊게 확인할 때만 각 레슨의 원문 블로그·영상 링크를 엽니다.

## 개별 레슨 상세 학습 노트

- 모듈 1~17의 Outcome School 블로그 **146개**를 각각 별도 한국어 상세 학습 노트로 정리했습니다.
- `README.ko.md`와 각 모듈 문서의 원문 링크 바로 아래에서 해당 한국어 노트로 이동할 수 있습니다.
- 모듈 0의 영상 자료는 [YouTube 영상 한국어 요약](videos.md)에서 확인할 수 있습니다.
- 모듈 18은 별도 Outcome School 블로그가 없는 면접 준비 모듈입니다.
